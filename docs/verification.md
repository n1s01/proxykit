# Проверка реализации

Дата: 4 октября 2026 года. Локальная среда: macOS arm64, Go 1.26.2.
Результаты относятся к структуре из основного пакета `proxykit` и отдельного
пакета `relay`; публичный конструктор возвращает `*Dialer`.

| Проверка | Результат |
|---|---|
| `make coverage` | PASS с race detector; итоговое покрытие 85,7% statements |
| Матрица Layout | PASS: 648 допустимых случаев (36 форматов × 3 типа host × 6 префиксов), 156 недопустимых сочетаний @ отклонены |
| `go vet ./...` | PASS |
| `go build ./...` | PASS, включая HTTP, TCP и browser examples |
| `make fuzz` | PASS: два targets по 10 секунд; 1 516 713 автоматических и 1 498 267 Layout-входов, crash не обнаружен |
| `GOOS=linux GOARCH=amd64 go build ./...` | PASS |
| `GOOS=windows GOARCH=amd64 go build ./...` | PASS |
| `go list -m all` | Только основной модуль; сторонних зависимостей нет |

Сетевые тесты используют настоящие TCP/TLS соединения на loopback. Проверены
HTTP, HTTPS и SOCKS5, авторизация, ошибки CONNECT и target TLS, remote target
DNS, IPv6 encoding, HTTP/2 до HTTPS target внутри TLS proxy tunnel, отмена,
timeout, buffered bytes, большие payloads, HTTP status/redirects, ограничение
числа workers, relay и закрытие активных соединений.

Матрица форматов проверяет все 24 colon-порядка и 12 порядков с @ между
соседними host/ip и port. @ между остальными полями отклоняется. Проверяется
явное назначение полей даже с числовыми credentials,
IPv6 в любой позиции, алиасы login/username и pass/password, сокращённые записи,
точность разделителей и URL round trip. Дополнительные регрессии проверяют
неоднозначность, numeric passwords, сохранение стандартной URL-семантики,
недопустимые Layout и отсутствие credentials в ошибках. Подтверждена передача
Layout через New, JSON-строки и списки. Автоматический разбор не может определить
произвольную перестановку login/password по тексту: для неё нужен явный Layout.

Тесты публичного API подтверждают общую конфигурацию маршрута для discovery,
Check и рабочего трафика, возврат копии endpoint, отмену конструктора и
отсутствие I/O при явном протоколе. Проверены ошибки при неинициализированном
диалере, nil tunnel и соединении, возвращённом вместе с ошибкой. В последнем
случае relay закрывает соединение, не оставляя его открытым.

Unit-тесты и внешние тесты `proxykit_test` находятся рядом с кодом библиотеки;
пакет relay имеет собственные unit-тесты. Coverage собирается по обоим пакетам
через `-coverpkg=.,./relay`, а итог берётся из
`go tool cover -func=coverage.out`. Примеры компилируются и не включены в процент.

Linux и Windows здесь проверены компиляцией, без исполнения сетевых тестов.
Минимальный Go 1.22 указан в `go.mod`; локально использовался Go 1.26.2.
CI workflow включает Go 1.22 и stable на Linux, stable на macOS и Windows;
удалённый CI в этой сессии не запускался.

Внешние коммерческие прокси, Chromium и Telegram DC/MTProto не проверялись.
Обход VPN проверен вручную утилитой `examples/bypass` при включённом VPN:
на macOS и на Windows с TUN-режимами sing-box, xray и Clash. На Linux —
только компиляцией.
